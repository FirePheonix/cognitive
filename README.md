# cognitive

Lightweight Next.js (React 19) + Tailwind v4 starter with:

- Landing page at `/`
- Docs at `/docs`
- Static export via `npm run export`

## Dev

```bash
npm install
npm run dev
```

## Static export

```bash
npm run export
```
