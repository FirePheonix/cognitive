# Appendix H — New Architectures

The rest of this book is about one architecture: a transformer trained on next-token prediction, scaled up, aligned, and served. That architecture is not standing still. New models keep changing what it is shaped like, what it outputs, and which jobs it is actually good at.

![Appendix H: new architectures that are not “chat, but bigger” — starting with Jev, a System One model that returns typed decisions instead of prose.](/appendix-h/new-architectures-arc.png)

This appendix looks at those new architectures one at a time: what each one does differently, what problem it is aimed at, and where it fits in a production system.

---

## What's in this appendix

**Chapter 29 — Jev: System One Models**
Most backend AI calls are not conversations. They are tiny judgment calls: is this spam, which team owns this ticket, does this need a human. Jev is a model built for exactly that. It reads application state and returns typed decisions instead of generated text. This chapter covers why autoregressive LLMs are a poor fit for decision workloads, how a System One model works differently, and where it breaks down.
