# 6. The Math Bridge

Appendix B is about to throw neural networks at you. Forward passes, loss functions, backpropagation, gradient descent. Before any of that makes sense, there are three mathematical operations you need to be comfortable with — not at a deep level, just enough to read what's happening.

This chapter covers exactly those three: **dot products**, **matrix multiplication**, and **activation functions**. Nothing here requires calculus or linear algebra. If you can follow a recipe, you can follow this.

---

## Operation 1: The Dot Product

A dot product takes two vectors of the same length, multiplies them element by element, and adds everything up. That's the whole thing.

```
a = [1, 2, 3]
b = [4, 5, 6]

dot(a, b) = (1×4) + (2×5) + (3×6)
           =   4  +   10  +  18
           =  32
```

![Dot product by hand. Three pair-multiplies: 1×4 = 4, 2×5 = 10, 3×6 = 18, then add them to get 32. One number comes out; it is large when the two vectors point the same way.](/appendix-a/06-maths/dot-product-by-hand.png)

One input (two vectors), one output (one number). Simple.

**Why it matters:** the dot product measures how much two vectors "agree" — how much they point in the same direction. If `a` and `b` are parallel (pointing exactly the same way), the dot product is large and positive. If they're perpendicular (completely unrelated), it's zero. If they're opposite, it's negative.

You've already seen this: cosine similarity is a normalized dot product. When we compute how similar two embeddings are, we're computing a dot product. When a language model scores how much a query "attends to" a key in the attention mechanism, it's a dot product. When a neural network multiplies inputs by weights, it's a dot product.

The dot product is everywhere.

## Operation 2: Matrix Multiplication

Matrix multiplication is just many dot products computed at once.

Take two matrices `A` (shape `m × k`) and `B` (shape `k × n`). The result `C = A @ B` has shape `m × n`. Each entry `C[i, j]` is the dot product of row `i` from `A` with column `j` from `B`.

```
A shape: (2, 3)    B shape: (3, 2)    C = A @ B shape: (2, 2)

A = [[1, 2, 3],    B = [[7,  8],
     [4, 5, 6]]        [9,  10],
                        [11, 12]]

C[0,0] = dot([1,2,3], [7,9,11])  = 7 + 18 + 33 = 58
C[0,1] = dot([1,2,3], [8,10,12]) = 8 + 20 + 36 = 64
C[1,0] = dot([4,5,6], [7,9,11])  = 28 + 45 + 66 = 139
C[1,1] = dot([4,5,6], [8,10,12]) = 32 + 50 + 72 = 154
```

![Matmul step 1. The top-left cell of C is one dot: row 0 of A (yellow) with column 0 of B (blue). 1×7 + 2×9 + 3×11 = 58. The other three cells of C are still unknown.](/appendix-a/06-maths/matmul-step-1-one-cell.png)

![Matmul step 2. Fill the rest the same way: C is 58 and 64 on the first row, 139 and 154 on the second. A neural-net layer is this picture with thousands of rows (the batch) and hundreds of columns (the next width).](/appendix-a/06-maths/matmul-step-2-all-cells.png)

**Why it matters for neural networks:** every layer in a neural network is a matrix multiplication. The input is a tensor of shape `(batch, features_in)`. The layer's weight matrix has shape `(features_in, features_out)`. Multiply them and you get `(batch, features_out)` — a new representation of the same batch, transformed by the learned weights.

The entire "thinking" in a neural network is repeated matrix multiplication, layer after layer.

`x @ W + b` — that one line is a complete neural network layer. The weight matrix `W` is what gets *learned*. The bias `b` is a small offset that also gets learned. Training is the process of finding values for all the `W`s and `b`s across all layers that make the model's predictions accurate.

## What Are Weights, Actually?

![weights-in-neural-nets](/appendix-a/06-maths/what-are-weights.png)

A weight is just a number inside a matrix. Nothing more. When people say "a 7 billion parameter model," they mean a model with 7 billion individual numbers (weights) organized across thousands of matrices and bias vectors.

![weights-in-neural-nets](/appendix-a/06-maths/representation.png)

![weights-in-neural-nets](/appendix-a/06-maths/weights-in-neural-nets.png)

Before training, all weights are random. During training, they get adjusted — very slightly, many billions of times — until the model produces good predictions. After training, they're frozen.

The "intelligence" of a language model lives entirely in the specific values of its weight tensors. There's no code that says "cats are similar to dogs" — that relationship is encoded in patterns across billions of floating-point numbers.

## Operation 3: Activation Functions

Here's a problem with matrix multiplication: no matter how many layers you stack, the output is always a linear function of the input. A linear function of a linear function is still linear. You could collapse a thousand matrix-multiply layers into one.

**Activation functions** break this. After each matrix multiplication, you apply a simple non-linear function element-by-element to the result. This forces each layer to be genuinely different from the last — the model can learn curved, complex decision boundaries, not just straight lines.

![sigmoid](/appendix-a/06-maths/sigmoid.png)

The three activations you'll encounter most:

**ReLU** (Rectified Linear Unit) — the simplest: replace every negative number with zero.
```
ReLU(x) = max(0, x)
ReLU([-2, -1, 0, 1, 2]) = [0, 0, 0, 1, 2]
```

![ReLU](/appendix-a/06-maths/relu.png)

(another activation function used a lot is tanh):
![tanh](/appendix-a/06-maths/tanh.png)

**GELU** (Gaussian Error Linear Unit) — a smooth version of ReLU. Used in most modern Transformers including GPT and BERT. Allows small negative values through rather than hard-zeroing them.

![GeLU](/appendix-a/06-maths/gelu.png)

**Softmax** — turns a vector of arbitrary numbers into a probability distribution: all values become positive and sum to 1. Used at the output of a language model to convert logits into "probability of this token being next."

```
softmax([2.0, 1.0, 0.5]) = [0.62, 0.23, 0.15]
                                ↑ all positive, sum = 1.0
```

![Softmax step 1 — exponentiate. Logits 2.0, 1.0, 0.5 for {the, a, cat} become e^z ≈ 7.39, 2.72, 1.65. Raw scores can be any real number; exp makes them positive.](/appendix-a/06-maths/softmax-step-1-exp.png)

![Softmax step 2 — add them. 7.39 + 2.72 + 1.65 ≈ 11.76. That single sum Z is the denominator for every class.](/appendix-a/06-maths/softmax-step-2-sum.png)

![Softmax step 3 — divide by the sum. Probabilities ≈ 0.63, 0.23, 0.14, which add to 1. If the true next token is “the”, cross-entropy is −log(0.63) ≈ 0.46.](/appendix-a/06-maths/softmax-step-3-divide.png)

## Putting It Together: One Neural Network Layer

A single layer of a neural network is three operations in sequence:

1. **Matrix multiply**: `z = x @ W + b` — linearly transform the input
2. **Activation function**: `a = gelu(z)` — introduce non-linearity  
3. **Output `a`** — passes into the next layer, which does the same thing

That's it. Stack enough of these layers, train the weights on enough data, and the network learns to do remarkably complex things.

## The Bridge Is Complete

Here's the full journey from text to prediction, in the vocabulary you now have:

```
"The cat sat"
    ↓  tokenizer
[1169, 3797, 3332]          ← 1D int tensor, shape (3,)
    ↓  embedding lookup
[[...], [...], [...]]       ← 2D float tensor, shape (3, 768)
    ↓  stack into batch
[[[...], [...], [...]]]     ← 3D float tensor, shape (1, 3, 768)
    ↓  matrix multiply + GELU  (× many layers)
[[[...], [...], [...]]]     ← 3D float tensor, same shape, transformed
    ↓  final matrix multiply → logits
[[50257 numbers]]           ← shape (1, 3, 50257) — one score per vocabulary token
    ↓  softmax on last position
[0.0003, 0.0001, ..., 0.002, ...]  ← probability distribution over vocab
    ↓  pick highest (or sample)
"on"                        ← next predicted token
```

Every arrow in that chain is either a tensor operation, a matrix multiply, or an activation function. There's nothing else.

## Quick Recap

- **Dot product**: multiply two vectors element-wise, sum the results. Measures directional similarity. The fundamental building block of neural networks.
- **Matrix multiplication** (`A @ B`): many dot products at once. One matrix-multiply + bias = one neural network layer.
- **Weights** are the numbers inside the weight matrices. They start random and get learned during training.
- **Activation functions** (ReLU, GELU, softmax) introduce non-linearity after each matrix multiply — without them, stacking layers would accomplish nothing.
- A complete layer is: `output = activation(input @ W + b)`.

Appendix B picks up exactly here. You now have everything you need to understand how neural networks learn — the forward pass, the loss, and backpropagation.
