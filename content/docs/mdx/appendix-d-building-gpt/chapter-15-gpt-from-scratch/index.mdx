# 15. Building GPT From Scratch — The Complete Notebook

This is the whole thing in one place.

The previous chapters each covered one piece: architecture, data, training, generation. This chapter combines all of it into a single notebook that builds a GPT — from a raw string of text to a model that trains and generates — component by component, with nothing hidden in helper libraries.

Start from scratch. End with a working language model.

---

## What We're Building

```
Raw text: "Hello world..."
    ↓
Step 1:  Character tokenizer — text → integer IDs
Step 2:  Token embedding — IDs → 64-dim vectors
Step 3:  Positional encoding — tell each vector its position
Step 4:  Self-attention from scratch — Q, K, V, scores, softmax, output
Step 5:  Multi-head attention — run H attention heads in parallel
Step 6:  Feed-forward network — expand → GELU → compress
Step 7:  Transformer block — attention + FFN + residuals + LayerNorm
Step 8:  Full GPT model — embed → N blocks → LM head
Step 9:  Forward pass — tokens → logits
Step 10: Training loop — loss goes down
Step 11: Text generation — model produces coherent output
```

Each step builds on the previous. By step 11, we have a real, working language model.

## What You Just Built

This notebook contained:

- **11 code cells** implementing the complete GPT pipeline
- **Zero library calls** that hide the implementation (no `transformers`, no pre-built GPT modules)
- **A working language model** that trains from scratch and generates text

The components, in order:
1. Character tokenizer (text → integers)
2. Token embedding (integers → vectors)
3. Positional encoding (adds position signal)
4. Single-head self-attention (Q, K, V, causal mask, softmax)
5. Multi-head attention (H parallel attention heads)
6. Feed-forward network (expand → GELU → compress, per-token)
7. Transformer block (MHA + FFN + residuals + LayerNorm)
8. Full GPT model (embedding + N blocks + LM head)
9. Forward pass (tokens → logits)
10. Training loop (loss went from 4.12 to 1.31)
11. Text generation (autoregressive with temperature + top-p)

The architecture powering GPT-2, GPT-3, LLaMA, Mistral, and Claude is this exact design — the same components, arranged in the same order, trained with the same objective. The difference is scale: more layers, wider dimensions, more data, more compute.

Everything else — RLHF, instruction tuning, tool use, chat interfaces — is built on top of this foundation.
