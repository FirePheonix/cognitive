# Appendix F — Beyond the Model

A fine-tuned, aligned language model is powerful — but it's still an island. It only knows what was in its training data, it can't look anything up, it can't run code, and it can't take any action in the world.

This appendix covers the systems that extend LLMs beyond text generation into useful applications.

---

## What's in this appendix

**Chapter 20 — Embeddings for Search**

The embedding vectors from Appendix A have a second life completely separate from language generation: semantic search. This chapter covers how embedding models convert text into vectors, why cosine similarity measures meaning better than keyword overlap, and how to build a working semantic search pipeline. Includes the full ASCII math for cosine similarity, a from-scratch search implementation, and a head-to-head comparison against keyword search.

**Chapter 21 — Vector Databases and RAG**

Semantic search against a million documents requires more than a matrix multiply. This chapter covers ANN (Approximate Nearest Neighbour) algorithms, HNSW's layered graph structure, and how vector databases wrap all of this for production use. Then: RAG (Retrieval-Augmented Generation) — the architecture that lets an LLM answer questions from documents it was never trained on. Includes a complete minimal RAG implementation: index, retrieve, build prompt, generate.

**Chapter 22 — Tool Calling and AI Agents**

LLMs have two hard limits: knowledge cutoff and imprecise arithmetic. Tool calling solves both. This chapter covers the full six-step tool call protocol (define → inject → model outputs JSON → execute → inject result → respond), parallel vs sequential multi-tool calls, how models are trained to use tools, the four common failure modes with mitigations, and how repeated tool calling becomes the agent loop. Complete working implementation with error handling.

## The arc

![Appendix F in four cards: semantic search, vector databases and RAG, tool calling, then the agent loop.](/appendix-f/beyond-the-model-arc.png)

Each layer builds on the previous. Embeddings enable search. Search enables RAG. Tool calling enables agents. Together they transform a text generator into a system that can work with real-world data, real-time information, and external computation.
