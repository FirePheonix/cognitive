## Alert Thresholds

```python
COST_ALERTS = {
    # Spike detection
    "daily_spend_multiplier": 2.0,      # Alert if today > 2× yesterday
    "hourly_spend_max": 5.00,           # Alert if any hour exceeds $5

    # Budget alerts
    "monthly_budget_warning": 0.80,     # Alert at 80% of monthly budget
    "monthly_budget_hard": 0.95,        # Alert at 95% — escalate

    # Feature anomalies
    "feature_cost_multiplier": 3.0,     # Alert if feature cost > 3× rolling average
}

def check_cost_alerts(daily_costs: dict):
    today = daily_costs["today"]
    yesterday = daily_costs["yesterday"]

    if yesterday > 0 and today / yesterday > COST_ALERTS["daily_spend_multiplier"]:
        send_alert(
            level="warning",
            message=f"Daily spend spike: ${today:.2f} today vs ${yesterday:.2f} yesterday",
        )
```

## LangSmith for Traced Agents

LangSmith provides per-run cost tracking for any agent that uses LangChain. Costs appear in the trace UI automatically:

```python
from langchain_anthropic import ChatAnthropic
from langchain_core.callbacks import LangChainTracer

# Costs are tracked automatically per trace
llm = ChatAnthropic(
    model="claude-sonnet-4-6",
    callbacks=[LangChainTracer(project_name="production-agent")],
)
```

Navigate to LangSmith → your project → click any trace → see token counts and cost in the sidebar.

## Grafana / DataDog Integration

For full control, pipe LiteLLM cost data to your observability stack:

```python
# Send cost metrics to StatsD (Grafana / DataDog compatible)
import statsd

statsd_client = statsd.StatsClient("localhost", 8125, prefix="llm")

def track_with_statsd(response, feature: str, tenant_id: str):
    cost = litellm.completion_cost(completion_response=response)
    tokens = response.usage.total_tokens

    # These become Grafana time-series graphs
    statsd_client.gauge(f"cost.feature.{feature}", cost)
    statsd_client.gauge(f"tokens.tenant.{tenant_id}", tokens)
    statsd_client.incr(f"calls.feature.{feature}")
```

Grafana dashboard panels to build:
- **Time series**: daily spend by model (line chart)
- **Bar chart**: cost by feature (weekly aggregation)
- **Gauge**: current month spend vs. budget
- **Alert rule**: trigger PagerDuty if hourly spend exceeds $5
