# ML Fundamentals

Classical machine learning is still the backbone of most production AI. This section covers every foundational ML algorithm — each one explained from first principles and implemented from scratch in Python.

You do not need deep learning experience. If you can read Python, you have enough background for everything here.

---

## What's in this section

**Chapters 1–3** cover the supervised learning essentials: what ML is, linear regression, and logistic regression. These three lessons establish the entire ML workflow — define a model, define a loss, optimize the parameters.

**Chapters 4–6** introduce the algorithms that dominate tabular data: decision trees, SVMs, and K-nearest neighbors. Each builds on limitations of the previous one.

**Chapter 7** flips to unsupervised learning: clustering, dimensionality reduction, and finding structure without labels.

**Chapters 8–10** are about the craft: feature engineering, model evaluation, and the bias-variance tradeoff. These are the highest-leverage skills in applied ML.

**Chapters 11–12** cover ensembles (bagging, boosting, stacking) and hyperparameter tuning — turning good models into great ones.

**Chapters 13–18** go deep on specialized topics: ML pipelines, Naive Bayes, time series, anomaly detection, imbalanced data, and feature selection.

**Chapters 19–21** bridge to production: ML system design, model monitoring and drift, and feature stores.

---

## A note on structure

Each chapter is self-contained with theory, from-scratch implementation, and production library usage. Code blocks are runnable Python. Every algorithm is implemented without libraries first, then shown with scikit-learn for comparison.

The natural reading order is sequential, but you can jump to any chapter that interests you.
